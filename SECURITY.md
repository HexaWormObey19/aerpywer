```powershell
# Reduce samples
# Render Settings > Samples = 16 (preview) or 256 (final)

# Lower resolution
# Render 2K for proofs, 4K only for finals
```

### Materials look wrong

```powershell
# Check HDRI lighting
# Environment > HDRI > Try different studio environments

# Adjust material roughness
# Material > Roughness = 0.2-0.8 (most materials in this range)

# Verify scale
# Model scale affects roughness appearance—ensure correct units
```

### Model import failed

```powershell
# Check file format
# File > Import > Supported: STEP, IGES, OBJ, FBX, STL

# Export from CAD
# Use STEP format for best compatibility from SolidWorks/Fusion

# Simplify model
# Reduce polygons/faces if model too complex (>10M polygons)
```
